# Proyecto Pajarería (Java)

## Descripción Funcional

Este proyecto es una aplicación de consola para gestionar una pajarería. Permite realizar operaciones básicas como el alta de clientes, la gestión de pájaros en el inventario y el registro de ventas.

## Requisitos para Compilar y Ejecutar

*   Java Development Kit (JDK) versión 11 o superior.
*   Tener configurada la variable de entorno `JAVA_HOME`.

## Instrucciones de Uso

1.  **Compilar:** Navegar a la carpeta `src` y ejecutar el siguiente comando:
    ```bash
    javac *.java
    ```
2.  **Ejecutar:** Desde la carpeta `src`, ejecutar la clase principal (asumiendo que se llama `GestionPajareria`):
    ```bash
    java GestionPajareria
    ```
